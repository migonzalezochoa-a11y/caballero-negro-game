# Caballero Negro 8-bit

Demo jugable creada en HTML5 Canvas con estilo retro 8-bit.

## Cómo jugar

1. Abre `index.html` en tu navegador.
2. Usa `WASD` para mover al protagonista.
3. Presiona `L` para atacar, `K` para giro y `Espacio` para activación especial.
4. Recupera las 5 estructuras, derrota al jefe y luego usa la nave.

## Archivos

- `index.html`
- `style.css`
- `game.js`

## Nota

La versión final está pensada para ejecutarse localmente sin compilación ni dependencias externas.
